# Synthetic sample data

All files here are **synthetic** and generated by `scripts/make_sample_data.py`. They do not describe real people and must not be used for any clinical purpose.

- `synthetic_metabolic_panel.pdf/.txt` - out-of-range glucose, HbA1c, lipids, haemoglobin, vitamin D, BP
- `synthetic_fever_cbc.pdf` - low platelets and white cells (dengue-like pattern) 
- `synthetic_fever_cbc_scan.png` - the same report as an image, to test OCR
- `synthetic_grayscale_image.png` - a synthetic image (not a radiograph) to test medical-image upload
